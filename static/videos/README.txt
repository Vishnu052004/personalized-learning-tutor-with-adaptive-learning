Place your lesson MP4 files in this folder structure so the website can play them directly:

static/videos/<course-slug>/<level>/<lesson-slug>.mp4

Examples:

static/videos/python-programming/beginner/python-introduction.mp4
static/videos/web-development/intermediate/modern-css-layout.mp4
static/videos/machine-learning/advanced/advanced-model-tuning.mp4

The lesson paths are defined in videos_data.py.
